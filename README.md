# Shanty Sonar EQ

**Shanty Sonar EQ** (Adamsky Music) — двухрежимный адаптивный эквалайзер и подавитель резонансов для macOS (AU / VST3 / Standalone) и Windows (VST3 / Standalone) в стилистике Шанти.

---

## Режимы работы

### 1. SONAR Mode *(аналог sonible smart:EQ 4)*
- **Profile**: выбор целевого профиля инструмента (*Universal, Vocals, Drums, Bass, Guitar, Keys / Synth, Speech, Master*).
- **LEARN**: включите воспроизведение трека и нажмите `LEARN` — Шанти просканирует спектр (~1.6 сек) и построит корректирующую кривую. `CLR` сбрасывает обучение.
- **IMPACT**: глубина применения умной кривой (`0–100%`).
- **SMOOTH**: сглаживание спектральной кривой.
- **ADAPTIVE**: динамическая подстройка спектра в реальном времени.
- **Smart Range**: перетаскивайте две голубые шторки вверху графика (`Min / Max Freq`), чтобы ограничить диапазон работы движка.
- **Unmasking (Межканальная расчистка)**:
  - Выберите общую группу (`Group A–D`) на нескольких экземплярах плагина в DAW.
  - Задайте приоритет (`Foreground`, `Midground`, `Background`).
  - Поверните `UNMASK` на треках с более низким приоритетом — конфликтующие частоты будут автоматически прорезаны и подсвечены красным. Также поддерживается внешний **Sidechain**.

### 2. SMOOTH Mode *(динамический подавитель резонансов)*
- **DEPTH**: глубина подавления острых резонансов (до `-18 dB`).
- **SHARP**: ширина детектирования — от мягкого разгребания мути до узкого хирургического вырезания свистящих резонансов.
- **SELECT**: порог избирательности (только явные пики или более широкое сглаживание).
- **ATTACK / RELEASE**: скорость срабатывания и восстановления.
- **Soft / Hard**: мягкий музыкальный или жёсткий хирургический характер.
- **DELTA**: прослушивание только вырезаемых резонансов (`dry - wet`).

## 12-полосный параметрический и динамический EQ
- **Клик по пустому месту на графике**: активирует следующую свободную полосу.
- **Перетаскивание узла**: изменение частоты (`Freq`) и усиления (`Gain`).
- **Колёсико мыши**: регулировка добротности (`Q`) выбранной полосы.
- **Правый клик по узлу**: отключение полосы.
- **Нижняя панель**: выбор типа фильтра (*Bell, Low/High Shelf, Low/High Cut 12–48 dB/oct, Notch, Bandpass, Tilt Shelf*), режима каналов (*Stereo, Mid, Side, Left, Right*), кнопка **SOLO** и полноценный **Dynamic EQ** (*Dynamic, Threshold, Range, Attack, Release*).

---

## Общие элементы управления
- **Zero-Latency / Linear Phase**: режим нулевой задержки для записи или линейно-фазовая STFT-обработка для сведения и мастеринга.
- **A / B**: сравнение двух состояний настроек.
- **AUTO GAIN**: автоматическая компенсация громкости.
- **`?` (Manual)**: встроенное руководство прямо внутри плагина (RU / EN).
- **Шанти-маскот**: реагирует на сканирование, громкость и подавление резонансов; можно погладить мышкой.
